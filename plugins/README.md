# Expo Plugins

This directory is reserved for custom Expo config plugins.

## Planned Purpose

- Custom Expo config plugins
- Native module configurations
- Build-time modifications

## Current Status

Currently empty. Plugin functionality is handled by:
- `app.plugin.js` - Main Expo plugin configuration
- `app.config.js` - Expo app configuration

## Future Implementation

When adding custom plugins, consider:
- Following Expo config plugin conventions
- Documenting plugin purpose and usage
- Testing on both iOS and Android platforms
