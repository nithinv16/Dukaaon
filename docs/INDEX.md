1. **For setup instructions**: Check `/docs/guides/`

## Contributing to Documentation

When adding new documentation:
- Place setup guides in `/docs/guides/`
- Place troubleshooting in `/docs/troubleshooting/`
- Place architecture docs in `/docs/architecture/`
- Archive completed fixes in `/docs/archive/`
- Update this index file
